Socket.io

Socket.IO enables real-time, bidirectional communication between clients and servers, so there's no need to 
refresh the page manually. This real-time functionality is achieved through WebSockets, a protocol that keeps
an open connection between the client and server. Here’s how it works:

Open Connection: When the client connects to the server using Socket.IO, a WebSocket connection is 
established and stays open as long as both client and server are active.

Event Listeners: Socket.IO allows you to set up event listeners on both the client and server. For example, 
on a chat application, you could have an event called message, where the server listens for incoming messages 
and sends them to all connected clients.

Emit and Listen Mechanism: When a client sends a message by emitting a message event to the server, 
the server receives it and can then emit that same message to all other clients. The clients listen 
for the message event and update the chat in real-time without requiring a page refresh.

Automatic Update: Since the WebSocket connection remains open, the server can push data to the client 
instantly, and the client's event listeners immediately capture this data and update the page dynamically. 
This makes it appear as if the page is "refreshing" in real-time, although technically, no actual page 
reload is happening.

So, Socket.IO handles communication and event handling under the hood, giving the appearance of 
live updates. This is why you don’t need to reload the page to see new messages or updates; they 
appear as soon as they’re sent from the server!
